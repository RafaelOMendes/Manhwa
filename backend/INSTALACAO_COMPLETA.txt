🔧 PRÓXIMOS PASSOS:

1️⃣  OBTER CREDENCIAIS DO TELEGRAM:
   → Acesse: https://my.telegram.org/apps
   → Faça login com seu número
   → Crie uma nova aplicação
   → Copie o api_id e api_hash

2️⃣  CONFIGURAR O ARQUIVO .env:
   → Abra: backend\.env
   → Substitua:
      - seu_api_id_aqui → Seu API ID
      - seu_api_hash_aqui → Seu API Hash
      - +55seu_numero_aqui → Seu número com DDD

3️⃣  TESTAR A INTEGRAÇÃO:
   → cd backend
   → python test_telegram_import.py
   
   (Na primeira vez, você receberá um código no Telegram)

4️⃣  USAR VIA API:
   → Inicie o servidor: python main.py
   → Teste: http://localhost:8000/api/telegram/test
   → Importe: POST /api/telegram/import

📚 DOCUMENTAÇÃO COMPLETA:
   Veja: backend\TELEGRAM_SETUP.md

🎯 EXEMPLO DE USO (após configurar):

   # Via Python
   python test_telegram_import.py

   # Via API (PowerShell)
   Invoke-RestMethod -Method POST `
     -Uri "http://localhost:8000/api/telegram/import" `
     -ContentType "application/json" `
     -Body '{"channel_link":"https://t.me/c/2296450302/9","limit":50}'

💡 DICAS:
   • O canal precisa ser público OU você precisa ser membro
   • Na primeira vez, um arquivo .session será criado
   • Não compartilhe suas credenciais ou arquivo .session
   • Adicione .env ao .gitignore (já está!)
